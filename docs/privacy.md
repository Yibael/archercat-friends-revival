# 隐私与分发

公开文件通过 `PUBLIC_FILES.txt` 明确列出，`DISTRIBUTION.json` 记录内容 hash。项目只复制运行所需文件，不包含原逆向仓库历史。

## 不分发的内容

- 运行日志、崩溃报告、截图、临时测试输出。
- `.venv`、依赖缓存、PlayCover 已安装应用及容器数据。
- 个人游戏存档、账号信息、cookies、SSH 私钥或访问令牌。
- 本机绝对目录、真实 Git 作者邮箱和与运行无关的本机诊断信息。
- provisioning profile、签名私钥，以及 IPA 内已移除的旧 entitlement 元数据。

## IPA 的边界

分发对象是重建的 unsigned IPA，不是从个人 PlayCover 容器导出的应用。已检查 ZIP 成员，未发现用户 Documents / Library / Preferences、个人存档、provisioning profile 或 iTunes 账号元数据。

原游戏二进制包含旧第三方库的原厂编译路径等静态信息；这些不是本次运行电脑的路径。为保持原版可执行文件不变，没有修改这些二进制内容。公开的应用 ID、协议字段名和 mock 的 `LocalGuest` / 占位 token 也不是个人凭据。

扫描器检查常见私钥、访问令牌和本机路径模式，并递归检查 IPA。模式扫描有边界，不构成“二进制里绝不可能存在未知信息”的保证。新增资产或日志应单独审查，不能只依赖 `.gitignore`。

## 提交和报告问题

运行时日志可能含客户端标识或请求数据。请勿强制加入被忽略的日志、存档或证书。报告问题只保留必要、已脱敏的错误片段。

首次发布使用 GitHub 用户名及 noreply 邮箱作为仓库本地提交身份，避免公开本机 Git 配置中的私人邮箱。后续提交者应自行核对自己的提交身份。

## 随仓库提供的 Frida

Frida wheel 直接来自 PyPI 的官方文件地址，SHA-256 与原锁文件记录一致。保留 wheel 内的原始许可证和元数据。其原生库含 PEM 解析标记和 URL 格式示例等公开字符串；扫描器仅在官方 wheel hash 完全一致时允许这些匹配，仍检查本机路径和其他令牌模式。wheel 未从本机虚拟环境重新打包，也没有附加本机配置。
